## 「安い」で見落としやすい3点

### 1. メモリ単価で見ると最安プランは割高

VM-0.5は$2.99で512MBだから、1GBあたり$5.98。VM-1は$5.99で2GBだから1GBあたり$3.00で、ちょうど半分になる。VM-0.75（$4.99 / 1GB）は$4.99/GBで、最も割高なのはこの中間プランだ。

512MBで足りるかどうかが分岐点になる。足りないと感じた時点でVM-0.75を挟まず、VM-1まで上げたほうがいい。差額は$1で、メモリが1GBから2GB、ストレージが10GBから20GB、転送量が750GBから1,000GBに増える。

コア数が必要なら、VM-1からVM-1.5で+$0.96。メモリは2GBのままでコアだけ2倍になる。

### 2. 年間コストは月額の積み上げで計算する

料金ページに表示されているのは月額で、年払いの割引額や更新時の金額は確認できていない。12か月分を月額で積み上げると、VM-0.5が$35.88、VM-1が$71.88、VM-2が$143.88。

長期で使う前提なら、注文画面で請求サイクルと更新時の請求額を先に見ておく。ここが読み切れないまま年単位で契約するのが、格安VPSで一番よくない買い方だ。

### 3. 追加IPは1本$3/月

IPを増やす場合、1本あたり月$3。最安プランの月額とほぼ同じで、2本目を足すとVM-0.5の料金が2倍になる計算だ。複数IPが前提の使い方をするなら、プランを上げる前にIP込みの総額で比較したほうがいい。

## よくある質問

**月$2.99のVM-0.5で何が動く？**
メモリ512MB、ストレージ5GB、転送500GB（大阪・香港は250GB）。静的サイト、Bot、監視、VPNの端点といった軽い用途なら足りる。WordPressにプラグインを数個入れる、Dockerで複数コンテナを動かす、DBを載せる、といった使い方ではメモリが先に尽きる。5GBという容量も、ログとアップデートで埋まりやすい。

**同じプランで地域を変えると何が変わる？**
月額と構成は同じで、月間転送量だけが変わる。香港・大阪・マレーシア（プレミアム）はスタンダード地域の半分になる。

**支払いに使える方法は？**
クレジットカードとデビットカードでの購入が案内されている。それ以外の決済手段は確認できていないため、必要なら注文画面で選択肢を確認する。

**バックアップは別料金？**
週次のオフサイトバックアップが全プランに追加費用なしで付く。

**IPは増やせる？**
1本あたり月$3で追加できる。料金と引き換えに、IP管理や付け替えの操作はパネルから行える。
